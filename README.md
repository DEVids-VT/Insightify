# Crypto Microservice Application

## Awards 
- 1st prize with gold medals at the Bulgarian Mathematical Society's Student Science Section
- 1st place in the national IT tournament 'John Atanasoff'

## Short Description

Insightify is an innovative platform designed for tracking cryptocurrencies, news, and social posts. The system is optimized for high performance and scalability to serve a large number of users seamlessly.

**Key features:** 
- Quick and easy access to up-to-date information on cryptocurrencies.
- Monitor the latest news and trends in the crypto industry.
- Ability to exchange opinions and discussions through social posts.
  
**Technological innovations:**
- Microservice architecture
- Using .NET Core and ASP.NET Core
- Combining relational and non-relational databases
- Caching with Redis Inter-system 
- Communication with RabbitMQ
- Real-time communication with SignalR
- Containerization with Docker
